## Overview

OrgoReactor is a photobioreactor (PBR) system developed as a part-time project for Zaara Biotech to support the cultivation of phototropic microorganisms under controlled environmental conditions.


![Hero Image](/assets/Rayan.jpg)

The system integrates embedded electronics, environmental control, user interaction interfaces, and automation workflows to regulate critical cultivation parameters such as temperature and pH levels. The project focused on creating a customizable and user-friendly reactor platform capable of supporting controlled biological growth processes.

---

## Key Features

* Embedded photobioreactor control system
* Temperature and pH regulation workflows
* Memory touch display user interface

## System Architecture

The OrgoReactor system consists of:

* Embedded processing unit
* Memory touch display interface
* Environmental sensing subsystem
* Temperature regulation system
* pH monitoring and control workflow
* Valve control subsystem
* User-configurable automation architecture

The system enables users to configure operational parameters and monitor reactor conditions through an integrated control interface.
